# 이노스피치 키오스크 공개 업데이트

설치파일과 업데이트 정보만 공개합니다. 개발 소스는 별도 비공개 저장소에서 관리합니다.

## 자동 업데이트 시험 (1.36.0 → 1.36.1)

1. 기존 앱과 사진·메일·출력 작업을 마치고 종료합니다.
2. [자동 시험용 1.36.0 Setup](https://github.com/innospeechb2b/TDI-updates/releases/download/v1.36.0/Innospeech-Kiosk-1.2-v1.36.0-Setup.exe)을 설치하고 실행합니다.
3. 기본 ON 상태에서 새 버전을 자동 다운로드합니다. 5초 카운트와 조작 금지 안내 후 자동 적용·재실행되어야 합니다.
4. 관리자 하단 버전 1.36.1과 기관·프린터·메뉴·사용량 유지를 확인하세요.

기존 1.35.x는 이번 버전을 한 번 수동 적용해야 새 자동 방식과 5초 안내가 들어갑니다. 관리자 → 업데이트 관리에서 자동 업데이트를 OFF로 바꾸거나 수동 적용할 수 있습니다.

학교·일자리센터 프로필 적용 시 AI 변신사진은 기본 OFF, 축제는 ON입니다. 관리자가 개별 변경할 수 있습니다. 공개 배포본에는 공용 API 키가 없으며 AI 도우미와 유료 사진 API 대체는 비활성화됩니다. GPT·Gemini 계정 연결과 로컬 배리어프리 안내는 유지합니다.

연결 실패·시간 초과 시 기존 앱을 열고, 일반 화면 진입 후에는 늦은 다운로드를 자동 설치하지 않습니다. 차등 실패/캐시 없음에서는 전체 설치파일을 받을 수 있습니다.

[최신 설치파일과 전체 버전](https://github.com/innospeechb2b/TDI-updates/releases)
